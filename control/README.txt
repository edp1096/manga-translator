Manga Translator
Windows x64 / Linux x64 / Linux ARM64

실행
1. 배포 ZIP을 쓰기 가능한 폴더에 풉니다.
2. Windows는 MangaTranslator.exe, Linux는 ./manga-control을 실행합니다.
3. 관리 화면: http://127.0.0.1:8794
4. 설치 관리에서 모델과 실행 구성을 선택하고
   '선택한 조합 다운로드·복구'를 누른 뒤 API를 시작합니다.
   필요한 모델·런타임은 앱에서 내려받습니다. GPU 사용 시 드라이버는 필요합니다.

확장 연결
1. 관리 화면의 '크롬 확장'에서 확장 폴더를 확인합니다.
2. Chrome은 chrome://extensions, Edge는 edge://extensions에서
   개발자 모드를 켜고 해당 폴더를 '압축해제된 확장 프로그램'으로 등록합니다.
3. 관리 화면을 새로고침하고 '확장 연결하기'를 누릅니다.
4. 만화 페이지에서 확장 아이콘을 눌러 번역 패널을 엽니다.
   확장 파일이 갱신되면 브라우저의 확장 관리 화면에서 새로고침합니다.

데이터와 종료
- 설정·모델·런타임·번역 결과는 기본적으로 실행 파일이 있는 폴더에 저장됩니다.
- 폴더를 옮길 때는 앱을 종료하고 폴더 전체를 옮깁니다.
- 관리 화면의 'API를 중지하고 앱 종료'로 종료합니다.
  브라우저 탭만 닫으면 앱과 API는 계속 실행됩니다.

새 버전으로 이전
1. 이전 앱에서 'API를 중지하고 앱 종료'를 누릅니다.
2. 새 배포본을 별도 폴더에 풀고 실행합니다.
3. 설치 관리의 '이전 버전 데이터 가져오기'에 이전 앱 폴더의 전체 경로를 입력합니다.
4. 완료 후 '선택한 조합 다운로드·복구'를 누르고 API를 시작합니다.

이전 폴더는 보존하며 복사할 여유 공간이 필요합니다.
새 폴더에 기존 데이터가 있으면 병합·덮어쓰지 않습니다.
브라우저의 명칭 사전·편집 기록을 보존하려면 기존 확장을 삭제하지 마세요.
폴더 이동 후에는 브라우저에 등록된 확장 경로도 확인하세요.
앱 자체의 자동 업데이트 기능은 없습니다.
