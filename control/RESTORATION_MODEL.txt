Manga LaMa optional restoration installation (2026-11-01)

The installer exposes restoration separately from layout, OCR and translation.
Downloading it enables both automatic and manual image restoration. It is not a
startup prerequisite for ordinary translation. Downloads are explicit; the model
is never fetched when an editing request is made. Missing-model responses are
translated into installation guidance by the extension.

Checkpoint CUDA integration (2026-11-01)
Windows x64 and Linux ARM64 now expose a separate LibTorch CUDA choice.
The default remains ONNX. Explicit CUDA restoration never falls back to CPU.
Install the optional model before selecting this backend. API startup loads
and warms the model three times, then retains it for automatic/manual requests.
The controller builds with CGO_ENABLED=0. Inference uses a C++ plugin and C ABI.
No Python interpreter or Python package installation is needed at runtime.

The deployed TorchScript .pt is converted from lama_large_512px.ckpt, not ONNX.
