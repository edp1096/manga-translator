만화 번역 설정

이 컴퓨터의 크롬에서 이미지를 읽고, 지정한 서버에서 OCR·번역합니다.

작품별 명칭 사전 관리 · 만화 패널에서 열면 현재 작품에 연결할 수 있습니다.

관리 페이지 열기

관리 화면의 크롬 확장 → 확장 연결하기를 누르면 연결됩니다. 원격 관리 페이지에서는 연결 코드를 한 번 입력하세요. 서버 주소와 인증 정보는 확장 연결 화면에서 자동 설정됩니다.

외부 서버 고급 설정

화면 캡처는 탭이 활성 상태일 때만 작동하며 화면 해상도로 처리합니다. 긴 세로 이미지는 분할 후 사용하세요.

한국어 번역 글꼴
자동은 기존 기본 글꼴을 사용하고, 원문 형태가 뚜렷하면 필기체·효과음 글꼴을 선택합니다. 개별 편집값이 우선하며 경량 처리에서는 기본 글꼴로 표시합니다. 별도 Bold 파일이 없으면 굵기를 합성합니다.
