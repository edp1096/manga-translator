이미지 복원 선택이 툴팁으로 돌아가는 원인 확인 및 런타임 갱신

원인: 사용자 Edge Profile 5의 캐시된 확장 background.js는 이전 버전이었다.
이전 코드는 msg.mode === white 이외의 값을 tooltip으로 치환한다.
새 panel.html/panel.js에는 restore 옵션이 있지만, 파일만 교체한 상태에서는
이미 실행 중인 서비스 작업자의 자바스크립트가 자동으로 바뀌지 않는다.

재현: 격리한 실제 Edge에 이전 확장을 로드한 후 파일만 새 버전으로 교체했다.
새 패널에서 이미지 복원을 선택하면 선택과 저장 값이 모두 tooltip으로 돌아갔다.
chrome.runtime.reload 후 같은 조작은 restore로 유지됐다.
results/mixed-version.json에 재현 전후 값과 Edge 버전을 기록했다.

사용자 프로필: 이전 캐시 분기를 확인했고, 확장 재로드 후 캐시가
['white','restore'].includes(msg.mode) 분기로 갱신된 것을 확인했다.
실제 87화 패널에서도 ‘이미지 복원’ 값이 유지됨을 UI Automation으로 읽었다.

재로드 중 이미 진행 중이던 번역의 기존 탭 연결이 무효화되었다.
완료된 6페이지 작업 b47b619d-f1b4-4e55-9406-81c55ad07392의 원본 PNG
SHA-256을 저장된 페이지의 원본과 비교해 정확히 대응시킨 뒤 결과를 복구했다.
현재 페이지 캐시는 먼저 백업했고, 일치한 항목 하나의 작업 ID/결과를 갱신했다.
다음으로 탭을 새로고침하고 남은 재번역을 이어가려 했으나 사용자의 87화 탭이
닫혀 No tab with id 오류로 중단했다. 다른 탭으로 작업을 옮기지 않았다.
이후 해당 회차를 다시 열면 저장한 결과가 복원된다. 남은 재번역은 재개하지 않았다.

소스/빌드 변경은 필요하지 않았다. 임시 재로드/복구 페이지는 제거했고,
현재 설치된 모든 확장 파일은 이전에 브라우저 검증한 소스와 SHA-256이 같다.
기존 모델·설정·인증 정보·명칭 사전은 변경하지 않았다.
