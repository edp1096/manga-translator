2026-10-27 말풍선·이름 상자 경계 교정

대상: https://klz9.com/isshou-senkin-chapter-88.html
작업 위치: 사용자가 승인한 현재 Windows 작업 폴더.
OP5P 원본을 덮어쓰지 않았으며 기존 Windows 설정·키·번역 자료는 보존한다.

확인한 원인

1페이지 사사키 치로루와 2페이지 혼고 히나는 이미 OCR·번역 결과가 있었다.
검출 모델의 글자 마스크는 말풍선 내부에 100% 포함됐지만, 여백을 포함한
검출 사각형의 안전 영역 포함률은 각각 0.89375, 0.887755였다.
기존의 0.94 사각형 조건 때문에 표시 대상에서 제외됐다.
18페이지 카지 마리코는 사각형 포함률이 1.0이라 같은 조건을 통과했다.

11페이지 두 번째 컷도 사각형 포함률 0.857142 때문에 글자 축소 이전에
제외됐다. 원문 마스크 inside=1.0, interior=0.983333으로 배치 근거는 있었다.
이번 결과에서는 '나를 지켜줘'를 13px로 배치했다. 잘린 원문의 뒷부분을
복원하거나 추측하는 기능을 추가한 것은 아니다.

10페이지 두 번째 컷은 가장 큰 글자가 들어가는 넓은 위쪽 상자가 선택됐다.
중심 거리 벌점이 페이지 전체 크기로 정규화되어 너무 작았던 것이 원인이다.
말풍선/분할 영역 크기로 거리 벌점을 계산해 27px, 두 줄로 중앙 부근에 놓았다.
흰 채움은 기존 톱니 모양 경계 안에서 이뤄진다. 투명 질감을 복원하는 처리가 아니다.

2페이지 첫 컷의 작은 구름형 말풍선은 별개였다. 원래 결과에는 해당 대사
영역 자체가 없었다. 전체 이미지의 약한 말풍선 후보를 확대 재검출하자
フッ가 인식됐고, 로컬 번역기가 '훗'으로 번역했다.
실제 Windows Edge 패널에서 2페이지만 재번역해 22px 흰 배경 표시를 확인했다.

공통 규칙 수정

- 중간 신뢰도 말풍선의 경우 글자 마스크 inside/interior 각각 0.98 이상을
  계속 요구하고, 여백이 있는 사각형의 보조 조건은 0.94에서 0.8로 조정했다.
- 번역문 크기 계산은 Canvas 실제 글리프 폭·좌우 경계·상하 경계를 사용한다.
  안전한 내부 사각형을 찾은 다음 허용하는 최소 크기까지 글자를 줄인다.
- 작은 약한 말풍선 후보만 최대 4개 확대 재검사한다. 페이지/URL/대사/이름
  문자열에 따른 분기는 없다. 겹치는 후보와 거의 같은 확대 범위는 합친다.
- 전체 페이지와 확대 영역의 말풍선 bbox IoU 0.6 이상, 확대 말풍선 신뢰도
  0.65 이상, 내부 글자 신뢰도 0.35 이상, 글자 bbox 포함률 0.98 이상,
  글자 면적이 말풍선의 절반 이하인 경우에만 새 영역을 추가한다.
- 확대 확인 근거를 말풍선과 해당 글자 모두에 기록한다. 회색/무늬 말풍선의
  짧은 대사가 effect로 분류돼도 두 근거가 모두 있고, 원문 마스크가 안전한
  내부에 98% 이상 포함될 때만 자동 흰 배경 대상으로 삼는다.
  기존의 큰 효과음에 이 예외를 적용하지 않는다.
- geometry v3로 갱신한다. 기존 캐시는 경계만 한 번 새로 가져오며,
  이미 있는 번역을 자동 재번역하지 않는다.

검증 범위와 결과

- Windows Edge 156.0.4314.42 실제 창, 실제 링크, 확장 도구 모음 및 패널 조작.
- 기존 사용자 캐시를 복사한 격리 프로필에서 20장 불러오기, 흰 배경 선택,
  PNG 내보내기, 새로고침, 탭 복귀, 기본 모드 복원, 2페이지 선택 재번역.
- 기존 20장은 재번역 없이 경계 요청을 각 1회만 실행했다. 다음 새로고침은
  캐시를 사용했다. 기본 모드 복원 PNG는 변경 전과 바이트 단위로 일치했다.
- 기존 캐시의 흰 배경 영역은 64개에서 67개로 늘었다. 2페이지를 새로
  번역하면 누락 대사 1개가 추가되어 68개에 해당한다.
- 실제 편집 창 적용, 자동 배치를 수동 배치로 저장하지 않는 동작,
  같은 말풍선의 빈 대사 보호, 편집/페이지 PNG 일치 확인.
- native 전체 번역: DirectML 검출·OCR, Vulkan 로컬 LLM. 2페이지 6개 영역,
  확대 검사 1회, 약 5.72초. 번역·OCR 내용은 모델 결과를 그대로 사용했다.
- 20장 + 다른 작품의 중복 제거 원본 111장 = 131장 native 경계 검사.
  이전보다 말풍선이 추가된 곳은 대상 2페이지 한 곳이었다.
  경계 요청 시간 중앙값 1.130초, 최대 1.426초(해당 Windows 환경).
- 다른 작품 111장의 자동 흰 배경 영역 449 → 450. 증가한 표본 20번 직접 확인.
  효과음의 흰 배경 승격 수는 7개로 동일. 공유 말풍선 그룹 26개.
  자동 배치 전체에서 글자 맞춤, 내부 포함률, 같은 그룹의 상자 겹침 검사 통과.
- 대상 만화 20장 전체 비교 화면과 문제 지점 원본 크기 화면을 검토했다.
  다른 작품은 전체 자동 검사와 표본 20, 29, 58, 111번 육안 검토를 구분했다.
- Edge/Chromium 공통 52개 배치 사례, 편집 6개 사례, 툴팁 겹침 8개 사례,
  패널 전체 표시·캐시 이전·내보내기·실패 시 원본 유지 회귀 검사 통과.
- native 경계 직렬화, 작은 후보 선별, 마스크 좌표 투영,
  192/288 크기 마스크 처리 검사 통과.

적용

소스 extension과 컨트롤러 내장 extension을 일치시켰다.
native Windows 실행 파일과 내장 gzip/catalog를 갱신했다.
컨트롤러는 CGO_ENABLED=0, Windows GUI 서브시스템으로 빌드했다.
설치 및 기존 자료 해시 보존 결과는 deployment.json에 기록한다.
설치 위치: dist/manga-translator-windows-x64-0.3.15/
백업 위치: archive/bubble-boundary-review-2026-10-27-before/
기존 배포 ZIP 파일은 갱신하지 않았다.

사용 중인 Edge에서는 확장을 다시 로드하고 만화 탭도 새로고침해야 한다.
패널의 흰 배경 표시를 사용하면 이름·10·11페이지는 기존 번역으로 갱신된다.
2페이지 작은 말풍선은 기존 결과에 번역이 없으므로 그 페이지만 재번역해야 한다.
사용자 원래 번역 데이터에 시험 결과를 덮어쓰지는 않았다.

한계

이 검증은 131개 원본의 검출/배치 회귀 검사다. 모든 향후 작품의 OCR·번역
정확성을 보장하지 않는다. 경계 불확실, 원문 잘림, 큰 효과음, 인식 누락은
여전히 있을 수 있으며, 2페이지 아래 컷의 불확실한 말풍선은 툴팁을 유지한다.
모델이 잘못 읽은 글자나 고유명사 번역 자체를 이 표시 수정으로 고치지는 않는다.
