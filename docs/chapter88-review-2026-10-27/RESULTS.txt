Isshou Senkin 88화 전체 페이지 검토 — 2026-10-27

검토 범위
실제 Edge Profile 5에 저장된 최신 번역 20장을 읽기 전용으로 확보했다.
별도 Edge 156.0.4314.42 프로필에서 실제 사이트와 확장 패널을 열고,
전체 본문을 불러와 원본 / 기본 표시 / 말풍선 흰 배경 자동 이미지를 저장했다.
1~20페이지의 비교 이미지 20개를 모두 직접 열어 대사, 말풍선, 그림을 대조했다.
현재 사용자의 확장 설정과 번역 결과는 바꾸지 않았다. 재번역하지 않았다.
캡처 메타데이터는 capture.json, 영역 데이터는 pages.json에 있다.
index.html을 열면 20페이지를 이동하며 원본과 두 표시 방식을 비교할 수 있다.

결론
현재 기능은 배경 복원이 아니라, 확인된 말풍선 내부를 흰색으로 덮는 기능이다.
단일 말풍선 일부에서는 유효하지만 회차 전체에서 일관되게 깨끗한 결과는 아니다.
특히 이미 직접 표시(replace)로 분류된 영역은 흰 배경 자동에서 제외되므로,
무늬 배경에 흰 삭제 띠가 남은 영역이 그대로 유지된다. 19·20페이지가 명확하다.

수치 (모델이 탐지한 영역 기준, 사람이 센 실제 말풍선 개수와 다름)
전체 148영역 = text 74 + effect 74.
표시: 기존 직접 표시 39, 자동 흰 배경 17, 툴팁 모드 92.
툴팁 모드 중 1영역은 번역이 비어 있어 실제 툴팁은 없다.
자동 흰 배경 17영역은 5·8·9·10·13·16·18·19·20페이지의 9장에 분포한다.
흰 배경이 말풍선 밖의 인물이나 인접 대사를 크게 덮어 지우는 사례는
이번 20장 육안 검토에서 발견하지 않았다. 말풍선 안쪽 그림과 무늬는 지워진다.

우선 확인된 문제와 원인
1. 흰 배경 모드가 기존 직접 표시를 보정하지 않는다.
   5·6·18·19·20페이지에 글자 주변의 흰 띠와 원래 무늬가 섞여 남는다.
   extension/render.js의 whiteCandidate는 mode=tooltip만 대상으로 삼는다.
   native/pipeline.hpp의 기존 글자 제거는 OCR 사각형 근처에서 색을 채운다.
   따라서 이를 통과한 replace 영역을 흰 배경 모드가 다시 검토하지 않는다.

2. 이어진 말풍선에 여러 대사가 있으면 모두 제외한다.
   8페이지 왼쪽의 두 텍스트는 같은 말풍선 마스크에 각각 100% 포함된다.
   하지만 다른 텍스트를 지우지 않기 위한 공유 말풍선 검사에 걸려 둘 다 원문 유지.
   같은 말풍선에 속한 대사들을 함께 배치하는 처리가 필요한 사례다.

3. 경계 탐지, 타입 분류, 안전 기준에서 빠지는 말풍선이 있다.
   1·2페이지, 6페이지 상단 오른쪽, 11페이지 가운데 오른쪽,
   16페이지 하단 왼쪽은 해당 경계가 보수적인 API 결과에 없다.
   이것이 원시 모델 미탐인지 신뢰도/경계 필터 탈락인지는 이번 자료만으로 단정하지 않는다.
   3페이지 하단의 작은 흰 말풍선은 effect로 분류되어 제외된다.
   18페이지 왼쪽 위는 경계 신뢰도 0.8618, 포함률 0.9583으로,
   현재 포함률 0.98 기준을 통과하지 못한다. 임계값을 일괄 완화하면 안전성 검증이 필요하다.

4. 말풍선 크기를 활용하지 못하는 글자 배치가 있다.
   흰색으로 채우는 범위와 글자를 놓는 사각형이 다르다.
   13페이지의 짧은 대사, 19페이지 하단의 긴 대사가 특히 작거나 세로로 길다.
   실제 Edge 캔버스로 측정한 최소 사례는 16페이지 가운데 오른쪽 9px.
   14페이지 하단 왼쪽은 12px/#777777, 15페이지 이름표는 11px이다.
   9페이지 한글 한 글자 폭은 31px, 글상자는 30px여서 가장자리 잘림 가능성도 있다.
   7페이지에는 삭제되지 않은 원문 물음표가 남는다.
   측정 결과는 metrics.json이며 렌더러가 실제 사용한 font/fillText를 기록했다.

5. 배경과 별개로 OCR·번역 품질 문제도 보인다.
   2페이지 ‘拳’을 ‘学者’로 인식하여 ‘학자’라고 번역한다.
   7페이지 ‘囚人’을 ‘因人’으로 인식하여 ‘원인을 데려오는’이라고 번역한다.
   16페이지의 마무리 공격이 불필요하다는 말이 ‘그만둘 필요 없어’가 된다.
   19페이지 ‘よせよ’가 ‘이리 와’가 된다.
   인명과 작품 용어도 페이지에 따라 달라진다.
   이번 검토는 전문 번역 교정 전체를 완료했다는 의미가 아니다.

개선 순서에 대한 판단
먼저 기존 replace 영역의 무늬 배경도 표시 정책에서 재검토하고,
같은 말풍선의 여러 대사 처리 및 말풍선 내부 글상자 배치를 개선할 필요가 있다.
경계/타입 보완과 작은 글자 대비를 그다음 함께 검증해야 한다.
원래 무늬와 그림을 살리는 인페인팅은 이와 별도의 기능이다.
페이지별 하드코딩 없이 공통 처리로 개선할 수 있는 부분과 모델 미탐을 구분해야 한다.

각 페이지의 구체적 관찰은 review.json과 index.html에 기록했다.
이번 요청은 전체 검토로 수행했으며 제품 소스나 설치 파일은 수정하지 않았다.
