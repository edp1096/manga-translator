0.3.14 — update frontend dependencies with published security fixes

npm audit reproduced the user's warning: 2 affected packages, Svelte
(moderate) and Vite (high). Multiple advisories are grouped by package.
The prior pins were Svelte 5.55.4 and Vite 8.0.10.

Updated exact pins:
- Svelte 5.55.7: patches the four reported Svelte advisories.
- Vite 8.1.6: patches the reported Vite/launch-editor advisories.
- @sveltejs/vite-plugin-svelte 7.0.0 remains compatible with both versions.
- Refreshed package-lock.json, including Windows optional build dependencies.

Application impact assessment:
build.sh/build.ps1 invoke vite build; they do not launch the Vite dev server.
The portable app serves prebuilt browser assets from Go. It does not ship or
run a Node/Vite development server. The client-only Svelte application does
not use SSR/hydratable, dynamic svelte:element tags, or user-controlled form
attribute spreading. The reported vulnerable use patterns were not found in
the current application, but the dependency versions were updated regardless.
A successful build and test run does not itself establish dependency security.

Validation:
- npm ci from the updated lockfile: found 0 vulnerabilities.
- Full npm audit (including dev dependencies): 0 vulnerabilities; raw JSON
  is included in npm-audit.json.
- Vite 8.1.6 production build passed.
- Production UI browser checks passed at 1440 and 390 pixel widths: model and
  preset selection, GPU compatibility controls, explicit downloads, settings
  layout, no horizontal overflow, and no browser console errors.
- The Svelte license text matches the bundled notice.
- Security audit instructions are documented in control/DEVELOPMENT.txt.
