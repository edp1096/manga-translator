패널 표시 방식 선택 — 2026-10-27

패널의 표시 방식에서 기본 표시 / 말풍선 흰 배경 자동을 선택한다.
기본값은 기존 표시다. 선택은 브라우저 확장 설정에 저장되고 다른 만화 탭,
나중에 불러온 페이지와 새 번역에도 적용된다. 이미지 체크박스와 무관하다.
기존 번역 결과는 재번역 없이 바뀐다. 경계 정보가 처음 필요한 페이지만
기존 로컬 API로 말풍선 탐지를 실행하고, 성공한 경계는 번역 캐시에 함께 저장한다.

자동 대상은 텍스트 유형의 툴팁이며, 기존 직접 표시와 수동 표시 선택은 유지한다.
기존 whiteBackground의 신뢰도, 경계 포함률, 최대 면적, 공유 말풍선 검사를 통과한
영역만 흰 배경으로 표시한다. 효과음, 불확실한 경계, 번역문 없는 영역은 유지한다.
원래 result와 표시용 result를 분리하여 기본 표시로 돌아올 때 데이터를 복구한다.
편집기에는 현재 표시를 보여 주되 글자 수정만으로 자동 표시가 영구 저장되지 않는다.
편집기에서 표시 방식을 직접 바꾸면 displayOverride로 자동 처리보다 우선한다.
