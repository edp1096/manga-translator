우라선데이·망가원 뷰어 추가 — 2026-10-28

요청한 주소
- https://urasunday.com/title/28501/359545
  현재 https://manga-one.com/manga/28501/chapter/359545 로 이동.
  ザ・ウェイ・ユー・アー 第1話: 본문38장.
- https://manga-one.com/manga/1924/chapter/354658
  日本三國 第51話: 본문23장.
각 회차 끝의 링크형 홍보 이미지1장과 추천 화면2개는 제외.

구현
- extension/readers.js: MangaOne 전용 어댑터. 뷰어가 이미 제공한
  페이지 종류/순번/총개수만 읽고, 실제 표시된 img를 캔버스로 읽음.
  페이지 이동은 사이트의 방향키 처리 사용. 별도 이미지 API 요청,
  암호 키 추출/복호화, 로그인·결제 우회 없음.
- background.js: 허용 호스트/최상위 프레임에서만 MAIN-world 메타정보
  함수 호출. 페이지 URL/슬롯/총개수 이외 값 반환하지 않음.
- content.js: 비동기 목록 준비, 가상화 DOM 교체 시 번역 재부착.
- names.js: 같은 작품의 Urasunday/MangaOne 주소를 하나의 사전 범위로 정규화.
- 회차 목록 쿼리와 임시 blob URL을 결과 식별자로 사용하지 않음.
- Chrome/Edge 공통 어댑터이며 기존 사이트별 이동 처리는 유지.
- 사이트 React viewerContainer의 children.props.src 구조에 의존함.
  구조가 바뀌면 명시적인 목록 읽기 오류로 중단하므로 후속 대응이 필요함.
  검증 범위는 현재 공개된 위 두 회차. 다른 모든 회차를 검증한 것은 아님.

검증
- 실제 Windows Edge, 실제 확장+패널+네이티브 OCR/번역.
- 두 회차 전체 본문 이미지 읽기: 38/38, 23/23 실패0.
- 실제 번역은 각 회차2페이지를 표본으로 수행: 각각7개,15개 영역.
  전체 회차를 OCR/번역한 것은 아님. 원본·결과 PNG를 직접 시각 확인.
- 앞/중간/끝 이동, DOM과 blob 재생성 후 동일 번역 픽셀 유지.
- 좁은 창 단일 페이지 배치, 번역/원본 토글, 회차 쿼리를 바꾼
  브라우저 새로고침 뒤 복원, 다른 탭 왕복.
- 실제 선택 저장 다운로드 ZIP: 0002.png + manifest.json.
  ZIP의 PNG와 화면 렌더 PNG의 SHA256 일치.
- 기존 카도코미18장(가로/세로), 토나리38장, 망가즈7장 실제 뷰어
  전체 읽기/번역 오버레이 위치/선택 보존/완료 후 강제복귀 없음 통과.
  이 회귀 검사의 번역 API는 모의 응답이며 신규 두 사이트의 네이티브
  실제 번역 검사와 구분되어 있음.
- 결정적 회귀6개 통과: reader_mangaone, reader_navigation,
  name_dictionary, name_background, panel_display, browser_tooltip_overlap.
  프레임 사이 추천 화면, 무시된 키입력, 늦은 애니메이션,
  숨김 탭 취소, 다른 회차 결과 혼입 방지 포함.
- Windows CGO_ENABLED=0 go test ./... 및 GUI 빌드 통과.
