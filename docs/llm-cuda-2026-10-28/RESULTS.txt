Translation uses official llama.cpp b11669 CUDA 13.4 Windows x64 binaries and
app-local CUDA dependencies, with archive SHA256s checked against upstream release
metadata and every installed file pinned in the catalog. No Python, CUDA Toolkit,
new model, or driver installation was required.

Runtime selection, validation, download dependencies, process GPU arguments,
CUDA_VISIBLE_DEVICES and manual UI selection now support CUDA translation.
Existing preset IDs (including gpu-12gb / E4B) resolve to CUDA on NVIDIA devices
with compute capability >=7.5 and CUDA driver API >=13.0; otherwise Vulkan.
Presets include the detected stable GPU ID, including mixed Intel/NVIDIA systems.
Manual unsupported CUDA selection fails rather than silently using CPU.
Windows installed driver API13040 and CC89 verified by Go/driver APIs.
Linux controller builds remain compatible; Linux CUDA LLM packages are not part
of this Windows-first delivery. Existing Linux CPU/Vulkan choices remain.
