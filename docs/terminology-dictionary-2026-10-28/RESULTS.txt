명칭 사전 개편 — 2026-10-28

현재 Windows 실행본에 적용 완료. 기존 인물 사전을 명칭 사전으로 확장했다.
- 인물 / 장소 / 단체 / 용어 / 호칭을 같은 목록에서 등록한다.
- 한 줄 편집, 상세 펼침, 검색, 종류 필터, 25개씩 페이지 이동, 총500개를 지원한다.
- 원문/확정 번역/읽기/별칭을 저장한다. 확인한 읽기에도 동일한 번역을 적용하는 선택 옵션을 제공한다. 후리가나 추정값을 자동 확정하지 않는다.
- 호칭은 별도짱/쨩 선택 대신 일반 항목이다. 원문과 번역 각각 앞/뒤 위치, 띄어쓰기, 번역 공란으로 생략을 지정한다. 등록된 인물명과 결합할 때만 적용한다.
- 원문 언어에 일본어/영어 제한은 없다. 실제 모델에서 일본어, 영어, 중국어, 스페인어, 포르투갈어 입력을 검증했다. Latin/diacritic 단어 경계로 Ann/Anna 등의 부분 문자열 오적용을 방지한다. 표기는 정확히 일치하는 것을 기준으로 하며 다른 형태는 별칭으로 등록한다.
- 번역 목표 언어는 기존 앱의 Korean/English/Chinese/Japanese 네 가지다. 작품의 언어별 사전과 적용 결과를 분리하여 한국어 사전이 영어/중국어에 들어가거나 기존 언어 사전 연결이 지워지지 않게 했다. 목표 언어 추가나 OCR 모델 교체는 하지 않았다.
- 저장 구조v2는 기존nameWorks와읽기/별칭/호칭을 호환한다. 기존형식은 열 때 읽고 새저장 때v2로 저장한다. 옛 항목의 종류는 인물 기본값이며 사용자가 변경할 수 있다.

남는 범위
사전은 등록된 명칭 표기를 통일하는 기능이다. OCR 오독, 모든 원문언어의OCR성능, 일반대사 의미오역, 후리가나자동확정까지 해결한 것은 아니다. 교정 범위를 검증하지 못하면 기존결과를 유지하고 확인필요 상태를 남긴다.
