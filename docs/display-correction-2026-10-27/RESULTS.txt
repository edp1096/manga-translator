말풍선 표시 공통 교정 · 2026-10-27

현재 Windows 작업 폴더와 실제 Windows 배포본에 반영했다.
관리 앱과 기존 관리 대상 API를 정상 종료한 뒤 새 빌드로 재시작했다.
사용자 Edge의 확장 다시 로드와 만화 탭 새로고침이 필요하다.
재빌드 또는 기존 페이지 재번역은 필요하지 않다.

구현
- URL, 작품명, 페이지 번호, 대사 문자열에 따른 예외 처리가 없다.
- 기존 직접 표시 영역도 흰 배경 자동 교정 대상으로 평가한다.
- 말풍선의 침식된 내부 마스크에서 실제 배치 가능한 사각형을 찾는다.
- 연결 말풍선의 대사를 함께 검사하고 서로 겹치지 않는 공간으로 나눈다.
- 미번역, 빈 대사, 수동 원문 선택, 삭제한 영역, 대응되지 않는 검출 글자가
  같은 배경에 있으면 전체를 덮지 않는다.
- 말풍선 탐지 신뢰도만 낮추지 않았다. 글자 마스크의 실제 포함 관계를
  추가로 검사한다. 효과음으로 분류된 글자는 닫힌 흰 영역이라는 이미지
  증거가 있을 때만 직접 표시 후보가 된다.
- 실제 폰트의 advance width와 actualBoundingBoxLeft/Right/Ascent/Descent를
  측정한다. 글자 외곽이 상자에 들어오는지 검사하고 같은 측정값으로 그린다.
- 줄바꿈과 배치를 먼저 찾고 폰트를 단계적으로 축소한다. 720px 기준 8px까지
  시도하며 해상도에 비례한다. 단어 분리를 줄이기 위해 최대 적합 크기의
  80% 미만으로 추가 축소하지는 않는다. 어떤 배치도 맞지 않으면 원문을
  보존하고 툴팁을 사용한다.
- 흰 배경 글자는 검정이다. 빈 번역문이나 전혀 들어가지 않는 번역문 때문에
  기존 글자만 지워지는 동작을 막았다.
- 자동 배치는 기본 결과에 저장하지 않는다. 수동 배치/글꼴/표시 선택은
  별도 유지한다. 편집기에서 재배치하고 페이지 적용·PNG와 결과를 맞춘다.
- 편집 적용 중에는 중복 적용과 입력 변경을 잠그고 완료 상태를 갱신한다.
- 기존 경계 캐시를 버전 2로 한 번 갱신한다. 새 캐시는 재로드 때 재사용한다.

요청한 회차 전체 검증
https://klz9.com/isshou-senkin-chapter-88.html
실제 Windows Edge 156.0.4314.42, 격리 프로필에서 실제 확장을 로드했다.
원래 사이트 DOM, 실제 확장 도구 모음, 실제 패널 선택기를 사용했다.
이미지는 사용자의 최신 저장 결과와 동일한 원본으로 고정하여 비교했다.
사용자의 정규 Profile 5를 직접 수정하지 않았다.

- 20장, 148개 검출 영역 전체를 렌더링/내보내기하고 직접 눈으로 검토했다.
- 흰 배경 직접 표시: 이전 17개 → 64개. 나머지 툴팁 83개, 기존 직접 표시 1개.
  툴팁 수에는 번역문이 비어 실제 툴팁을 그리지 않는 영역 1개가 포함된다.
- 1페이지 연결 대사 2개, 3페이지 작은 말풍선, 6페이지 상단 대사,
  8페이지 연결 말풍선, 16페이지 하단, 18페이지 대사 영역이 개선됐다.
- 5페이지 하단과 19·20페이지의 기존 부분 삭제/흰 띠를 말풍선 내부 채움으로
  바꾸었다. 문장부호를 홀로 다음 줄에 보내던 배치도 줄였다.
- 16페이지 작은 응답은 실제 글자 경계를 검사하면서 축소해 직접 표시한다.
- 경계 갱신 20회, 재번역 0회. 새로고침 후 추가 경계 요청 0회.
- 탭 이동 후 패널 유지, 기본 표시 복귀 시 PNG 픽셀 일치.
- 실제 확장 편집기에서 대사 수정→페이지 적용→PNG 저장 픽셀 일치.
  연결 말풍선의 대사를 비웠을 때 원문과 다른 대사 보존도 확인했다.

별도 검증 자료
- 기존 사용자 결과 중 위 20장과 원본 SHA가 다른 111장을 사용했다.
- 해상도 800×1138, 1127×1600, 1284×1826.
- 전부 실제 Windows 네이티브 엔진으로 경계를 추론하고 Edge로 렌더링했다.
- 자동 흰 배경 영역 449개, 공유 말풍선 그룹 26개, 효과음 분류에서 직접
  표시로 전환된 영역 7개. 상자 경계/글자 적합/공유 영역 겹침 자동 검사 통과.
- 별도 자료 12장(1,2,4,29,30,48,58,69,88,100,107,111)을 원본과 직접 대조했다.
  효과음 분류에서 전환된 7개 영역이 있는 5장은 모두 포함했다.
- 자동 검사는 문자 인식과 번역의 정답 판정이 아니다. 별도 111장 모두를
  사람처럼 정독했다고 주장하지 않는다. 전체 출력은 holdout/에 보관했다.

남은 한계
- 투명 배경의 그림을 복원하는 인페인팅을 구현한 것은 아니다. 선택한 흰
  배경 모드에서는 말풍선 내부를 흰색으로 덮는다. 경계 부근의 약간의 무늬는
  원래 선을 보존하는 안전 여백 때문에 남을 수 있다.
- 2페이지 하단의 복잡한 형태와 11페이지 잘린 대사는 경계 조건을 통과하지
  못한다. 1·2페이지 일부 이름 상자, 17페이지 장식 제목도 툴팁으로 남는다.
- 15페이지 상단의 기존 회색 세로 번역은 확실한 경계를 확보하지 못해
  기존 직접 표시를 유지한다.
- 작은 말풍선과 긴 번역은 축소되므로 읽기에는 확대가 필요할 수 있다.
- 기존 OCR 오인식, 잘못된 번역, 이름/용어 불일치는 수정하지 않았다.
  예: 2페이지 학자, 7페이지 원인, 16페이지 그만둘 필요 없어,
  19페이지 이리 와 등의 기존 결과는 여전히 별도 개선 대상이다.
- 131장 검사 통과는 앞으로의 모든 작품에 대한 정답 보장이 아니다.
  불확실한 경우 원문을 보존하는 규칙과 회귀 자료를 함께 남겼다.
