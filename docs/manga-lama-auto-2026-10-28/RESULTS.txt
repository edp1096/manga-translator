Windows 자동 마스크·Manga LaMa 확장 통합 완료

사용법
실행 폴더: dist/manga-translator-windows-x64-0.3.15
패널의 ‘대사·독백’에서 ‘툴팁 / 흰 배경 / 이미지 복원’을 선택한다.
선택한 체크박스와 관계없이 현재 불러온 모든 번역 결과에 적용된다.
첫 이미지 복원은 검출과 모델 처리가 필요하다. 이후 전환은 저장한 결과를
사용하며 OCR/번역을 다시 실행하지 않는다. 이후 새 번역에도 모드를 유지한다.
기존 Edge에서 이미 불러온 확장은 edge://extensions의 새로고침 후 만화 탭을
새로고침해야 새 코드가 로드된다. 빌드와 관리 앱 재시작은 완료했다.
기존 사용자 프로필의 확장 설정은 변경하지 않았다.

구현
- Koharu의 글자 분할 마스크를 실제 OCR 결과와 대응시킨다.
- 글자 크기·페이지 해상도·검출 격자에 맞는 여백을 적용하고 작은 글자 내부
  구멍을 채운다. 사각형 전체를 지우지 않는다.
- 효과음, 잘린 OCR, 신뢰도 낮은 검출, 다른 글자와 충돌하는 마스크는 제외한다.
- 확실한 말풍선뿐 아니라 원문을 둘러싼 낮은 점수의 말풍선 후보도 복원에서
  제외한다. 이 후보는 복원을 막는 데만 사용하며 흰 배경을 칠하는 근거로
  사용하지 않는다. 특정 작품·페이지 좌표 예외는 없다.
- 모델 결과를 원래 해상도의 정확한 마스크 픽셀에만 합성한다.
- 번역문이 실제 글꼴 측정으로 들어가지 않으면 그 영역을 지우지 않고 툴팁으로
  유지한다. 개별 편집·삭제 영역·다른 글자와의 충돌도 보호한다.
- 원본, 기본 번역, 투명 복원 이미지와 마스크 메타데이터를 분리한다.
- 모델/검출기/원문/알고리즘이 달라지면 캐시를 다시 생성한다.
- 각 페이지가 끝나면 복원 모델의 GPU 작업 공간을 해제한다. GPU 실행 오류는
  해당 페이지 전체를 CPU로 다시 처리하고 cpuFallback에 기록한다.
- 중지·연결 종료는 단계 사이에서 확인한다. 모드 전환 중 늦게 온 응답은
  화면에 적용하지 않는다. 진행 중인 단일 ONNX 호출 자체는 즉시 중단하지 않는다.
- 모델이 없는 설치에서는 일반 번역을 유지하고 복원 요청에 안내 오류를 낸다.

실측 검증
대상: https://klz9.com/isshou-senkin-chapter-72.html
72화 17페이지를 실제 Koharu/OCR/Gemma 번역과 자동 마스크로 처리했다.
자동 복원: 총 14곳 (4p 4, 6p 3, 8p 4, 11p 1, 13p 2).
17p의 투명 말풍선 두 곳은 복원하지 않고 원문을 보존했다.
모든 페이지의 최종 표시를 검토하고, 복원된 5개 페이지는 큰 이미지로 확인했다.
최종 전체 재검증의 복원 API 소요: 페이지당 1.29–4.69초.
이 시간은 검출·모델 로딩·파일 저장을 포함하며 OCR/번역 시간은 포함하지 않는다.
모든 최종 72화 검증은 DirectML, CPU 대체 없음. 반복 요청은 캐시를 재사용했다.

추가 실제 OCR/번역/복원 검사
- 72화 13p 1440×2040: 동일한 두 독백 복원.
- Urasunday 다른 작품 도입부: 낮은 점수의 컬러 문구 3곳을 원문 보존.
- MangaOne 다른 작품: 효과음을 복원하지 않고 기존 말풍선 번역 유지.
- 88화 5p: 투명 말풍선 두 곳을 원문 보존.
다른 작품 검사는 보수적 제외 동작을 검증했다. 다른 작품의 복원 성공 품질까지
입증한 시험은 아니다. 이 소량의 표본으로 모든 작품의 정확도를 보장하지 않는다.

Edge 실제 확장 검사
- Edge 156.0.4314.50, 창을 띄우고 실제 확장을 로드.
- 실제 72화 사이트에서 17페이지 결과 표시.
- 패널 3개 모드 전환, 원본 보기, 새로고침 후 복원.
- 편집기·내보낸 PNG와 페이지 표시의 픽셀 일치.
- 재번역 없이 전환, 저장된 복원 재사용.
- 복원 모드를 켠 채 패널 버튼으로 13p 새 번역.
- 배포된 관리 앱·네이티브·확장으로 다시 새 번역: 2곳 DirectML 복원.
  배포 확인 작업 ID: 17f1f00c-048c-4dd8-a09d-e710765423cd
- 사용자 브라우저의 다른 탭이나 프로필 대신 격리한 테스트 프로필을 사용.

회귀 및 오류 경로
- CGO_ENABLED=0 Go 전체 테스트와 Windows GUI 빌드 통과.
- C++ 마스크 경계 30개 검사: 1×/2×/4×, 주변 글자·효과음·말풍선 보호,
  불완전 OCR·약한 분할·불확실한 말풍선 후보 제외.
- Edge 렌더러: 정확한 픽셀 마스크, 개별 편집, 들어가지 않는 문장, 잘못된
  RLE 6개, 원본 복귀 검사 통과.
- 패널: 순차 처리, 늦은 응답 무시, 409 재시도, 편집/저장, 새 번역 상속,
  캐시 및 새로고침 검사 통과. 새로고침 시 복원 준비 전에 표시 완료로
  처리하던 문제를 이 검사에서 찾아 수정했다.
- 인증 없는 복원 401, 없는 작업 404, 번역 진행 중 409.
- CUDA가 없는 DirectML 런타임을 지정한 실패 실험: 페이지 전체 CPU 대체,
  두 영역 복원, 캐시 재사용 확인. 모델 누락 500에서도 원본 접근 유지.

한계
배경 복원은 그림을 추정한다. 촘촘한 선·망점·컬러 그림에서 흔적이나 무늬
변형이 남을 수 있다. 검출 누락과 분류 오류 자체를 모두 해결한 것은 아니다.
좁은 원문 영역은 작은 글자나 잦은 줄바꿈으로 표시될 수 있다.
원문 보존·흰 배경으로 언제든 전환할 수 있다. 의미/이름 번역 품질은 별도다.
