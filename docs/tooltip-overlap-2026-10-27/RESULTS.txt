Overlapping translation tooltips — 2026-10-27

Problem and fix
On the supplied KLZ chapter, a later large effect region intercepted the mouse
over smaller text regions. Tooltip spans previously followed detection order.
The display now inserts larger tooltip regions first, so smaller overlapping
regions receive mouse hover. The native help cursor and title tooltip remain.
Only the filtered display array is sorted; cached result order, bounding boxes,
translations, rendered canvas pixels and export data are unchanged.
This resolves tooltip hit priority, not oversized model detection itself.
