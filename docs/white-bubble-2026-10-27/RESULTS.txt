Selective white-background translation — 2026-10-27

Implemented behavior
- The editor has a White background translation display mode and a background
  extent selector: speech-bubble interior or text-box area. It is opt-in for
  each region. Tooltip/original display remains available.
- Existing saved jobs can request bubble geometry without OCR or translation.
  The authenticated native POST /api/jobs/{id}/bubbles endpoint loads the
  original and runs the selected layout model/provider only. It does not
  modify the saved job, translation or cleaned image.
- Geometry includes high-confidence bubble masks as compact run-length data.
  The mask is clipped to the detection bounds and inset before being sent.
  Display smoothing removes the visible grid steps of the lower-resolution
  layout mask. The original bubble outline and exterior artwork are retained.
- The browser requires almost complete text-box coverage, rejects oversized
  candidates, effects and bubbles containing another text region, and offers
  an explicit text-box alternative. It never silently fills a large uncertain
  region. Busy translation jobs reject boundary requests with HTTP 409.
- White backgrounds are drawn before all translated text; text is black.
  Moving a text-box background paints the original and destination boxes
  separately, preserving the artwork between them. Bubble-mode text dragging
  is constrained to the white interior. Empty translations do not erase text.
- The same renderer supplies the editor preview, manga overlay, PNG and page
  export used by ZIP saving. Serialized edits retain the mask across reloads.
  Switching back to tooltip restores the original rendering exactly.
- The editor opens in the originating manga window, including when the site
  opens an advertisement in a separate window.

Usage
Reload the extension and the manga tab. Open the panel and the page's editor,
select a dialogue region, choose White background translation and Speech-bubble
interior, then Apply to page. Choose Text-box area if a reliable single-bubble
boundary is unavailable. Existing cached results do not need retranslating.
